# Ideation: divergent concepts, a diverse set, and copy

## 1. Beat the first-idea trap

Your first ideas are the most available ones. That means competitors, and every other LLM, produce them too. Later ideas in a session are measurably more original (Beaty & Silvia 2012).

1. **Cliché inventory first.** Start from the *Cliché zone* in `research.md` (claims and visuals seen in ≥3 competitor ads), then add the expected visuals and lines from memory, up to 10 or more. Example for fintech: phone with a rising chart, a piggy bank, a "take control of your finances" headline, blue-purple gradients, a smiling person at a laptop. Concepts that land in this list are banned unless they deliberately subvert it.
2. **Volume, written down.** Write ≥15 one-line concept seeds into `concepts.md`. Ideas kept "in your head" don't count. Drop the first ~25% and anything in the cliché inventory.
3. **Push with the divergence levers** (Smith & Yang). Ask of each seed:
   - *Originality:* has the category ever shown this?
   - *Flexibility:* is it a totally different viewpoint (the product's, the enemy's, a bystander's)?
   - *Elaboration:* does it carry one unexpected, specific detail?
   - *Synthesis:* does it blend two unrelated worlds?
   - *Artistic value:* does it rest on one striking craft choice?

## 2. Techniques (use ≥3 different ones per brief)

| Technique | How | Example prompt |
|---|---|---|
| Gap mining | Start from the *Gaps* in research.md: angle × archetype cells that VOC cares about and no competitor uses | "V-pain with no A-ad" |
| Angle matrix | Persona × pain/desire × awareness × CEP × archetype. Pick cells that are far apart | "anxious first-year freelancer × tax surprise × problem-aware × April × notes-app" |
| Angle families | Price/value, proof/trust, convenience/time, transformation, identity, FOMO, enemy (old way), mechanism, guilt-free, gift/occasion, values, status | "Which family has the category ignored?" |
| Reversal / anti-ad | Do the opposite of the category convention: honest flaw, "don't buy this if…", a bad review flipped into the hook | Avis "We're No. 2" |
| Exaggeration | Push the benefit to an absurd visual extreme | "So quiet a drum kit becomes a library" |
| Visual metaphor / synthesis | Fuse the product with an object that carries the benefit. It must decode in <2 s | VW "Think Small"; The Economist wordplay posters |
| Forced connection | A random object, profession or cultural moment, linked to the SMP, then checked for relevance | "a parking meter → time running out on unpaid invoices" |
| What would X do? | Re-imagine the ad as Apple (minimal), Liquid Death (irreverent), The Economist (wit), a tabloid, a museum label, an airline safety card | |
| Demonstration | A fair side-by-side test or a measurable difference in one frame | Pepsi Challenge, split frame |
| Customer verbatim | A real review line as the headline (needs permission and a source) | |
| Enemy framing | The old way, the habit or the category is the villain (not a named competitor unless it is legally safe) | "Spreadsheets are where receipts go to die" |
| Native disguise | Notes app, iMessage, tweet, Reddit post, sticky note, receipt, handwritten letter | Must not fake system UI (strategy.md §6) |
| SCAMPER | Substitute, Combine, Adapt, Magnify, Put to other use, Eliminate, Reverse, applied to the product *or* the ad convention | |
| Brand device | A recurring character or scenario that can carry a campaign | IPA: fluent devices give +50% dwell time |

## 4. The set must be diverse (Meta Andromeda era)

- Meta's retrieval engine (Andromeda, Dec 2024) is built for large pools of *diverse* creatives. Meta advises visibly different visuals, formats and messages. Near-duplicates add little delivery [S/M].
- **New concept** = different angle/pain/persona **and** a different visual world/archetype.
- **Iteration** = same concept with a new headline, colour, crop or background. Use iterations only to optimise a proven winner.
- For a set of N concepts, require:
  - ≥3 distinct angles.
  - ≥ceil(N/2) distinct archetypes.
  - Both emotional and rational ads.
  - Both lo-fi/native and polished ads.
  - No two ads sharing layout + image.
  - **One wild card**: the highest-divergence concept that still passes the gates.
- When a stakeholder mandates an idea, build theirs as the **control**, fully crafted. Add ≥2 challengers from other rows, and present the control first. A static challenger costs minutes, and the live test settles it.

## 5. Copy rules

- **Headline:**
  - ≤8 words (ideal 3–6) on social.
  - ≤5 words on 728×90 and 320×50.
  - Billboard ≤7 words.
  - Front-load the hook in the first 3 words.
  - The headline must sell alone: 5× more people read it than the body (Ogilvy).
- **Total on-image words:** ≤20–25 (excluding legal). Platform text fields carry the rest. Native/text-led archetypes (notes app, letter, tweet, receipt) may exceed this on purpose; QA will warn, so state the exception in the report.
- **Specific beats general:** "Cut 3 h of admin a week" beats "Save time". Precise numbers (4.8★, 12,417) read as more credible than round ones.
- **Customer language over brand language.** Use VOC phrases. Never "We're proud to…".
- **Image + headline = 1 + 1 = 3:** don't caption the picture; each should add meaning the other lacks.
- **Formulas as scaffolds:** PAS, AIDA, BAB, FAB (feature → "so that…" → benefit). Score headlines with the 4U test (useful, urgent, unique, ultra-specific).
- **CTA:** verb + value, matched to the stage. Cold: "See how it works", "Take the quiz". Warm: "Start free trial", "Get 30% off". Put risk reducers nearby ("Cancel anytime"). Evidence for specific CTA words is weak, so test.
- **Avoid:** puns that need explaining, confusing negations, jargon, ALL CAPS beyond 4 words, exclamation stacks.
- **Write platform text fields too:**
  - Meta: primary text ~125 chars before "See more", headline ~27–40 chars.
  - Google RDA: headline 30, long headline 90, description 90.
  - LinkedIn: intro ≤150 chars.

**Rubric** (1–5 each). Score it *after* rendering, from the image, not from the idea. A score ≤2 on a **gate** item kills the concept.

| Item | Gate? | 5 means |
|---|---|---|
| on_brief | gate | Expresses the SMP for this persona and awareness level |
| single_minded | gate | One message, understood in <2 s at phone size (squint test) |
| branded | gate | Brand identifiable with the logo covered (DBA present) |
| divergent | | Not in the cliché inventory; a competitor's logo would not fit |
| relevant | | The surprise points straight at the benefit |
| emotional | | A clear feeling (amusement, relief, desire, curiosity) |
| believable | gate | Claims backed by RTBs in the claims ledger |
| stopping_power | | Contrast, face/eyes, unusual composition or native disguise |
| direction | | CTA matches the stage |
